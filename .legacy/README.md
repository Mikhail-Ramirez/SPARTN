# OLD README Drone Detection Network (SPARTN)
## Setup and Installation

Follow these steps to set up the project locally.

### 1. Clone the Repository
Clone the project repository from GitHub (replace `<repository_url>` with the actual URL):
```bash
git clone https://github.com/Mikhail-Ramirez/SPARTN.git
cd SPARTN
```
### 2. Create Virtual Environment
Create a virtual environment to manage project dependencies:
```bash
python3 -m venv env
```
### 3. Activate the Virtual Environment
Activate the virtual environment:
```bash
source env/bin/activate
```
### 4. Install Dependencies
Install the required packages using pip:
```bash
pip install -r requirements.txt
```
### 5. Run the App on the Pi
Start the Application
```bash
python integration/moment_of_truth.py
```
